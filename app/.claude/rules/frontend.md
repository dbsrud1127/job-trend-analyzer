# Frontend Rules (v1: Jinja2 템플릿)

- v1 화면은 FastAPI 가 렌더링하는 Jinja2 템플릿으로 만든다. React 는 v2.
- 템플릿에는 계산 로직을 넣지 않는다. 계산은 service 함수가 하고, 템플릿은 결과를 보여주기만 한다.
- 공통 레이아웃은 base.html 하나를 만들고 각 페이지가 상속한다.
- CSS 는 파일 하나로 단순하게. 별도 프레임워크나 빌드 도구를 쓰지 않는다.
- 차트가 필요하면 CDN 으로 불러오는 가벼운 라이브러리 하나만 쓴다 (빌드 과정 없음).
- 디자인은 화려함보다 "데이터 흐름이 눈에 보이는 것"에 집중한다.
- v1 화면 (09-27):
  1. 직무별 기술 통계
  2. 내 기술스택 입력 (익명 프로필, id 는 브라우저 localStorage)
  3. 격차 분석 결과 + AI 학습 제안
